Covers no_safe_draft and missing_draft_body. Nothing to answerPrimary: Mark as done (out_of_office, automated, unsubscribe, usually not_interested). Out of office adds Remind me {date}. missing_senderPrimary: Connect inbox. Secondary: Call / Text / Email from the device. wrong_personPrimary: Help me write it, with Maya asking who the right person is.
Answers to the open questions. (1) After Mark as done or send, go to the next person, with an Undo toast for 5 seconds. Return to the list only when the count reaches zero (5d). (2) Yes, show the return date from replyClean. "Remind me {date}" needs a server snooze, so hide it until that exists. Notes for the build
The web app already renders draft HTML. The iOS app shows raw tags in Drafts and the draft editor, so it should render HTML too, or use replyClean and signalSummary, which the API already sends. The laptop sidebar mirrors the web app's sections: Growth, Signal Engine, Inbox, Composer, Catalyst. Inbox tags come from classification. TODD's decision chip comes from recommendedAction. Laptop shortcuts on 4d: A approve, R rewrite, T test, ← → previous/next. The same mapping works on the Angular web app and SwiftUI. Swap SwiftUI's default Form styling for these surfaces and pills.
